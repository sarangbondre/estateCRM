# Contract mocks (F-05)

These let any service run and be tested alone, with every other service replaced by its contract (CLAUDE.md §3.9).

## HTTP: Prism mock per OpenAPI spec
```bash
pnpm mock                      # all services, dynamic responses from the response schemas
pnpm mock records listings     # only these
pnpm mock records --static     # examples/defaults only
pnpm mock:smoke                # CI check: every mock starts, health is 200, protected routes return 401 without auth
```
Ports come from [`ports.json`](ports.json) (web 4010 … insight 4016). Point a service's dependency base URL (for example
`RECORDS_BASE_URL=http://127.0.0.1:4012`) at the mock. Prism validates requests against the spec, so an invalid call
gets the contract's 4xx, just as the real service would. Send any bearer token: mocks check that credentials are
present, not whether they're valid.

## Events: fixtures + publisher
- `contracts/fixtures/events/<eventType>.json`: one deterministic, schema-valid fixture per event. They're generated by
  `pnpm contracts:gen` and validated by `pnpm contracts:lint`. They contain no real personal data.
- `pnpm mock:event <eventType> [--to <consumer>] [--set data.path=json] [--keep-id] [--dry-run]` stands in for the
  producer's outbox relay. It sends the fixture, with a fresh `eventId`, to the consumers' `q_<consumer>` pgmq queues
  on the local stack (`DATABASE_URL`). Use `--keep-id` to replay the same `eventId` and test consumer dedupe.
