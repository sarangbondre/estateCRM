# 11estates CRM

An internal CRM for 11 Estates (Mumbai): ingest property ads and leads, classify them with a controlled deal vocabulary,
match demand to supply with the **CRM Engine**, run supply and demand journeys, publish listings to
[11estates.in](https://www.11estates.in), and ask questions in a chat-first UI that only answers from the CRM's own data.

## Repository layout
```
services/   web · intake · records · journeys · crm-engine · listings · insight   (each deployable alone)
libs/       db · outbox · http · auth · observability · vocabulary · redaction · testing (infrastructure only)
contracts/  OpenAPI per service + AsyncAPI events (generated by tools/)
infra/      Terraform + scripts (Vercel, Supabase)
loadtests/  k6 scenarios
tools/      generators for contracts, gate tables and tasks
```

## Prerequisites
Node 24 (`.nvmrc`), pnpm 12 (`corepack`), Docker (Supabase local stack), Terraform.

```bash
pnpm install
pnpm build
pnpm test
```
