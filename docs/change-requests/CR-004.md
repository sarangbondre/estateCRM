# CR-004: Clarify BRD A-10 (data residency) for AI processing

| | |
|---|---|
| Raised | 2026-09-24 |
| Raised by | Sarang Bondre (product owner), during Stage 3 |
| Affects | `docs/01-brd.md` v0.6 (approved), assumption A-10 and the Compliance constraint in §12 |
| Status | APPROVED 2026-09-24 |

## What
**Currently (BRD v0.6):**
> A-10: All data is stored and processed in India (Indian cloud region).

**Proposed:**
> A-10: All data is **stored** in India (Indian cloud region). **Personal data** (names, phone numbers, emails, unit-level
> addresses) is also **processed** only in India. Text with personal data removed, such as a property description or a
> chat question after redaction, may be processed by an AI inference endpoint (open-weight models on Hugging Face) outside
> India if no India region is available, under no-retention terms. AI answers are limited to the CRM's own data.

The Compliance row of §12 gets the same wording.

## Why
The product owner confirmed (2026-09-24) that Phase 1 needs AI for classification and chat, using Hugging Face inference
models, with answers scoped to the CRM's own data. Phase 1 runs on Vercel, which can't host models, so the models run on a
Hugging Face endpoint. An India region for that endpoint may not be available. PRD D-8 (no personal data to third-party
AI) stays in force, and the DPDP Act concern is personal data.

## Impact
- **BRD:** A-10 and §12 wording only.
- **PRD:** none. D-8 and NFR-14 already require redaction. NFR-12 (residency) is read with the new A-10.
- **HLD:** ADR-0004 is updated to Hugging Face open-weight models on a dedicated Inference Endpoint. The region is chosen
  in Stage 4, preferring India or the nearest available.
- **Risk:** redaction misses a phone number or name hidden in odd formatting. Mitigations: rule-based redaction plus a
  second pass that masks anything that looks like a phone number, email, or a proper name next to a contact phrase. The
  benchmark includes redaction tests, and every AI request is logged by ID and hash, never its content.
